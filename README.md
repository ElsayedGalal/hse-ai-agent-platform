# 🛡️ منصة الرصد الذكي للسلامة والصحة المهنية (HSE AI Platform)

منظومة ذكية متكاملة لإدارة ومراقبة السلامة والصحة المهنية (HSE) في المواقع الإنشائية والتشغيلية بالمملكة العربية السعودية، مدعومة بنماذج الرؤية الحاسوبية (Computer Vision) والتحليل المالي الاستباقي للامتثال وتفادي الغرامات النظامية.

## 📌 مميزات المنصة الرئيسية

* **الرصد البصري المؤتمت (AI Video Feed):** رصد آني لارتداء مهمات الوقاية الشخصية (PPE) كالخوذ، السترات العاكسة، وأحزمة الأمان، وكشف انسداد مخارج الطوارئ ومناطق الخطر.
* **مؤشرات أداء تنفيذية لحظية (Real-Time KPIs):**
  * نسبة الامتثال العامة لكل موقع تشغيلي.
  * مؤشر متوسط وقت التصحيح والإغلاق (MTTR).
  * عداد الغرامات المحتملة المتجنبة بالريال السعودي.
* **مسار عمل رقمي لإغلاق التذاكر (Digital Closure):** تحويل الرصد الميداني فوراً إلى تذكرة رقمية برقم تتبع مستقل وإجراءات إغلاق سريعة.
* **تقارير دورية معتمدة:** تصدير آلي لتقارير الامتثال الرسمية لتسهيل مراجعات السلامة وتوثيق التزام الموقع.

## 🏗️ الهيكلية التقنية (Tech Stack)

| الطبقة | التقنيات المستخدمة | الدور الوظيفي |
| :--- | :--- | :--- |
| **الواجهة الأمامية (Frontend)** | React 19, TypeScript, Vite, Tailwind CSS | واجهة عملياتية داكنة (Dark UI) تدعم اللغة العربية بالكامل (RTL) |
| **تصميم المكونات (UI Components)** | Radix UI, Lucide Icons | مكونات تفاعلية عالية الأداء وبطاقات زجاجية مخصصة |
| **محرك الرسوم البيانية (Data Viz)** | Recharts | تمثيل مؤشرات الأداء ونسب الامتثال إحصائياً |
| **محرك الذكاء الاصطناعي (AI & CV)** | Python, Ultralytics (YOLOv8), OpenCV | التعرف الآلي على مهمات الوقاية والانتهاكات الخطرة |
| **الخادم وقاعدة البيانات (Backend & DB)** | FastAPI / Node.js, PostgreSQL | إدارة الـ APIs وسجلات التذاكر والربط السحابي |
